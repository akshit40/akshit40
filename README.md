## Featured Projects

### 🛰️ EarthMind — Geospatial Intelligence
Full-stack geospatial intelligence platform combining computer vision, satellite data, multi-spectral workflows, and a command-center interface.

**Stack:** Next.js · FastAPI · PyTorch/TorchGeo · SQLite

→ [Repository](https://github.com/akshit40/earthmind-intelligence-platform)

### 🛡️ ShieldFlow — Local LLM PII Firewall
Local privacy layer for LLM applications that detects sensitive information, resolves overlapping entities, and substitutes PII while preserving prompt context.

**Stack:** Python · Microsoft Presidio · spaCy · Flask · Docker

→ [Repository](https://github.com/akshit40/pii-masking-engine)

### 🔍 PII Radar — Structured Data Scanner
CLI tooling for detecting PII in CSV, JSON, and Parquet data with validation, reporting, CI/CD integration, and automated redaction workflows.

**Stack:** Python · Click · Regex/heuristics · Luhn validation · GitHub Actions

→ [Repository](https://github.com/akshit40/PII-Radar)

### 🎧 AirBeatz — Computer Vision DJ Controller
Webcam-based virtual DJ controller using hand landmarks to control volume, playback speed, pitch, and track navigation in real time.

**Stack:** Python · OpenCV · MediaPipe · Pyo

→ [Repository](https://github.com/akshit40/AirBeatz)

### 🎨 AdSnap Studio — AI Ad Generation
Streamlit application for generating product advertisements with image generation, background removal, shadows, lifestyle scenes, and prompt enhancement.

**Stack:** Python · Streamlit · Bria AI

→ [Repository](https://github.com/akshit40/adsnap-studio)
